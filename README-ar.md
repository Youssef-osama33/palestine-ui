## ليه palestine-ui؟

كل مطور بيبني مشروع عن فلسطين بيبدأ من الصفر — ألوان، أيقونات، أنماط.
`palestine-ui` هو الأساس المشترك اللي يخليك تركز على اللي يهم.

**بيشتغل مع:** Vanilla JS · React · Vue · Svelte · أي framework
